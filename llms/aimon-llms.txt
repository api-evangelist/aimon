# AIMon

> AIMon (AIMon Labs) is an enterprise AI monitoring, evaluation, and governance platform for trustworthy LLM, RAG, and agentic AI applications. Its API and SDKs detect hallucinations and quality issues — instruction adherence, context quality, conciseness, completeness, and toxicity — across offline evaluation, continuous production monitoring, and inline/real-time detection.

- Base API URL: https://sdkbe-production.aimon.ai (version v1, URI path)
- Authentication: Bearer API key (Authorization: Bearer <AIMON_API_KEY>); keys at app.aimon.ai > My Account > Keys
- Generated by the API Evangelist enrichment pipeline from public AIMon surfaces on 2026-07-17

## APIs

- [AIMon API](https://docs.aimon.ai): LLM monitoring and evaluation — users, models, applications, evaluations, evaluation runs, evaluation/production metrics, datasets, dataset records, dataset collections.
